# Farcaster Mini Apps Guidelines

This document contains the full guidelines for building Farcaster Mini Apps, sourced from https://miniapps.farcaster.xyz/llms-full.txt

## Overview

Farcaster Mini Apps are lightweight applications that run within the Farcaster ecosystem, providing enhanced functionality for users while maintaining seamless integration with the protocol.

## Key Principles

1. **User-Centric Design**: Mini apps should prioritize user experience and provide clear value
2. **Protocol Integration**: Leverage Farcaster's social graph and casting mechanisms
3. **Performance**: Keep apps lightweight and fast-loading
4. **Security**: Follow best practices for handling user data and authentication

## Technical Requirements

### Authentication
- Use Farcaster Auth Kit for user authentication
- Support both real and demo modes for development
- Handle authentication failures gracefully

### Casting Integration
- Integrate with Farcaster's casting API
- Support embeds and rich media content
- Validate cast content before submission

### User Interface
- Mobile-first responsive design
- Clear navigation and user feedback
- Consistent with Farcaster design patterns

### Performance
- Optimize for fast loading times
- Minimize bundle size
- Use efficient data fetching patterns

## Best Practices

### Development
- Use TypeScript for type safety
- Implement proper error handling
- Include comprehensive testing
- Follow accessibility guidelines

### Deployment
- Use environment variables for configuration
- Implement proper CI/CD pipelines

### User Experience

## API Integration

### Farcaster Protocol
- Use official Farcaster SDKs when available
- Implement proper rate limiting
- Handle API errors gracefully
- Cache responses appropriately

### External Services
- Validate external API responses

- Monitor third-party service health
